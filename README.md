**Cyber-Terminal Ultimate** adalah game simulasi peretasan berbasis teks (*Command Line Interface*) interaktif yang sepenuhnya dibangun menggunakan **Python Standard Library**. Game ini dirancang tidak hanya untuk hiburan, tetapi juga sebagai unjuk kebolehan dalam hal logika pemrograman, penanganan state (*state management*), validasi input, dan desain antarmuka retro terminal.

---

## 🚀 Fitur Utama

*   **Sistem Multi-Level (Classic Mode):** Pilih tingkat kesulitan (`EASY`, `MEDIUM`, `HARD`) yang secara dinamis mengubah batas waktu berpikir dan jumlah kesempatan percobaan.
*   **Matrix Number Bypass Mode:** Mode tantangan tebak angka rahasia ala hacker film Hollywood dengan sistem analisis *feedback* per digit (petunjuk angka tepat, ada, atau salah).
*   **Dynamic Random Events:** Setiap ronde permainan bisa memicu *event* acak yang mengubah jalannya misi secara tak terduga (seperti *Time Rush*, *System Glitch*, atau *Stable Connection*).
*   **Streak & Scoring System:** Akumulasi poin berdasarkan tingkat kesulitan dan rentetan kemenangan (*combo streak*) beruntun.
*   **Zero Dependencies:** Berjalan murni menggunakan Python bawaan (`random`, `time`, `os`, `sys`). Tanpa perlu instalasi paket tambahan (`pip install` bebas!).
